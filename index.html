Официальные правила проекта. Здесь собраны требования к игрокам, использование аккаунтов, экономика, античит, наказания и правила администрации.

РАЗДЕЛ 01

Общие правила

Каждый игрок обязан соблюдать правила проекта. Использование игры означает согласие с действующими правилами.

1.1
Запрещено намеренно использовать ошибки игры для получения преимущества.
1.2
Запрещено вмешательство в работу сервера, API или игровых систем.
1.3
Игрок несёт ответственность за безопасность своего аккаунта.
РАЗДЕЛ 02

Аккаунты

Регистрация

Один Telegram ID может быть зарегистрирован только один раз.

После регистрации ID сохраняется в базе данных. Повторная регистрация этого ID невозможна.

Важно

Если Telegram ID уже используется, система должна сообщить:

«Этот ID уже используется.»

РАЗДЕЛ 03

Игровая экономика

Монеты являются игровой валютой проекта.

Монеты

Монеты можно использовать для покупки игровых улучшений и других доступных возможностей.

Законная игровая валюта

Монеты, полученные обычной игрой или официальной выдачей администрации, являются полноценной игровой валютой и могут использоваться в магазине.

Покупки

При покупке сервер проверяет наличие достаточного количества монет и только после этого совершает операцию.

РАЗДЕЛ 04

Античит

Проект использует серверную систему обнаружения подозрительной активности.

Запрещено
  • Автокликеры.
  • Боты.
  • Макросы, дающие нечестное преимущество.
  • Манипуляции запросами к серверу.
  • Эксплуатация ошибок античита.
  • Любое другое автоматизированное получение преимущества.

Анализ поведения

Античит оценивает не только отдельное действие, но и общую картину поведения игрока.

Подозрительная активность может привести к дополнительной проверке или блокировке аккаунта.

РАЗДЕЛ 05

Наказания

В зависимости от нарушения администрация может применить различные меры.

Предупреждение

Используется для менее серьёзных нарушений.

Временная блокировка

Игрок временно теряет доступ к игре.

Перманентная блокировка

Аккаунт может быть заблокирован без ограничения срока при серьёзных нарушениях.

РАЗДЕЛ 06

Администрация

Администрация отвечает за поддержание порядка, безопасность сервера и соблюдение правил.

Административные действия

Администрация может применять предусмотренные системой наказания и управлять игровыми ресурсами в рамках своих полномочий.

Административные действия должны регистрироваться серверной системой.

РАЗДЕЛ 07

Жалобы

Игрок может сообщить администрации о нарушении, подозрительной активности или технической проблеме.

В жалобе желательно указать
  • Telegram ID игрока.
  • Что произошло.
  • Примерное время нарушения.
  • Скриншоты или другие доказательства.
РАЗДЕЛ 08

Конфиденциальность

Для работы аккаунта проект может хранить необходимые идентификаторы и игровые данные.

Доступ к административной информации должен быть ограничен уполномоченными лицами.

РАЗДЕЛ 09

Изменения правил

Правила проекта могут изменяться при добавлении новых функций, изменении игровой механики или обнаружении новых видов нарушений.
